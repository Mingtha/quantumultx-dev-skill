# 评测

`evals.json` 是改 skill 之后用来回归的真实请求。格式检查只能证明文件结构没错，证明不了 skill 能让助手做出好的判断，所以每次改动后挑相关条目重跑。

每条包含：

- `prompt`：原样交给助手的用户请求，不附带答案或怀疑点。
- `should_trigger`：是否应该加载本 skill（`false` 用来检查描述不会误触发）。
- `expect`：结果里应该做到的事；`must_not`：出现即判失败。

运行方式：在一个独立的临时目录里启动助手，只提供本 skill 和 prompt 需要的最少文件，把输出逐条对照 `expect` 与 `must_not` 打分。生成的文件留在临时目录，不进入仓库。结果记录哪条没过、原文是什么，再只改有证据支持的地方。
